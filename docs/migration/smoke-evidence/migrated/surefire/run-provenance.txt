why the paths were replaced rather than kept:
  the baseline necessarily runs from a throwaway checkout of the base commit, so
  its path names a directory that no longer exists; and the two sides run from
  different roots by construction, so keeping the paths would make every report
  differ between the two sides for a reason unrelated to test outcomes, which is
  precisely what the row-for-row comparison must not be flooded with.
