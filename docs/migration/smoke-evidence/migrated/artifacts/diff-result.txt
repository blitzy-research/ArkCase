      found that satisfies the criterion.
    escape the affected pattern in the application source — tried, and rejected on

    upgrade or replace the two minifiers — not permitted and not effective: a build

      pattern, which yields the target-runtime bytes rather than the baseline ones.
    pass different options to the minifiers — not available: the task graph and the
      asset configuration are frozen contract files.
    normalise the built files after the fact — refused.  That fabricates build
      output, and a digest over fabricated output evidences nothing.
    regenerate the pre-migration digests from a target-runtime build — refused.  It
      would satisfy the comparison by redefining what it compares.
