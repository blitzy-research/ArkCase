why this file exists.  Three of the twelve digest records committed by an
earlier revision of this deliverable carried a path-qualified label
("assets/dist/application.min.js") that no code path in this script can
produce, which proves they were edited after capture.  Two captures whose
records label the same artefact differently cannot be compared by key, and
nothing in the previous reader looked at the label at all.  The schema is
now fixed where the record is written and asserted here where it is read
back, so an edited record is a recorded, capture-incompleting condition
rather than an invisible one.

a malformed record is NOT the same as an absent one: absence means the
artefact was not built and the remedy is to build it, whereas malformation
means the record cannot be trusted and the remedy is to re-capture it.
