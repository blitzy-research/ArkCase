# An advisory is "entered" when the baseline version sat outside every affected range and
# the delivered version sits inside one -- that is, the migration's own version advance
# moved the deployed artifact INTO the advisory.  That is a regression, not an inherited
# exposure, so triage-advisory-corpus.sh fails unless the entered set is exactly the set
# named here.  Listing an identifier is an assertion that
#   (a) docs/migration/backend-dependency-security.md discloses it, with the specific
#       Agent Action Plan clause that bars the remedy, and
#   (b) a human decision is recorded against it.
#
# The gate is set EQUALITY, deliberately, and in both directions.  A newly entered
# advisory is not silenced by this file, because it would not appear here.  An identifier
# that stops being entered also fails, because a stale acknowledgement is a claim about
# the build that is no longer true.  One line per identifier; # begins a comment.
#
