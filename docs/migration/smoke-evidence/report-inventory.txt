===== the counting rule, stated before any number =====
A SUITE is one TEST-<fully.qualified.Class>.xml file.  A DIRECTORY ENTRY is anything in
the archive directory, which includes two control files per half -- run-provenance.txt
and sha256-manifest.txt -- and, in the pre-migration half, a notes directory.  The two
are different numbers and are never used interchangeably below: an earlier revision of
the archive documentation published the directory-entry count as a suite count, which is
the whole reason this rule is written down.
