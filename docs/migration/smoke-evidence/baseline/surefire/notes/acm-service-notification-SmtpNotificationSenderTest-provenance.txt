     collaborator is a mock, so no delivery is attempted and no retry can occur.
10b. Coverage exclusions are NOT test exclusions. The root coverage plugin configuration carries
     eight exclusion globs which exclude package globs from coverage MEASUREMENT only. No test is
     disabled by them, and none of the eight matches this module's package. Relatedly and bindingly:
     the coverage agent's preparation execution communicates with the test runner through the
     default argument line property export, and its check goal evaluates a line covered ratio rule
     against a configured minimum of 0.02. The newly added unit test runner declaration must
     therefore NOT set a literal argument line element; doing so silently severs instrumentation and
     leaves the check goal evaluating an empty data set, which is a false pass. Instrumentation must
     be verifiably live. Verified at the base commit: the coverage plugin block contains no argument
     line element at all.
