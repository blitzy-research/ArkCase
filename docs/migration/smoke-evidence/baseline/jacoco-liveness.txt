why liveness is measured rather than assumed.  The coverage plugin
publishes its agent configuration through the default argLine property.  A
test-runner declaration that sets a literal argLine overrides it and
severs instrumentation with no diagnostic at all; the configured check
goal then evaluates an EMPTY execution data set against its minimum ratio
and reports a pass.  A capture that recorded only that the goal passed
could not tell that apart from a real pass.  Non-empty execution data,
measured per module off disk, can.
